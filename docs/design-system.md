# Design System

Tokens en `frontend/src/styles/theme.ts` (`C`): fondo `#07070f`, superficies, acento `#7c5cfc`, estados (green/red/amber/blue), gradientes. Tipografía display: Syne (headings), sistema para texto.

Componentes reutilizables: `frontend/src/components/ui` (Modal, Confirm, Spinner, Tag, Toggle, FileUploadZone, MiniChart). El AI Creative Studio usa estos tokens con cards de bordes suaves, estados de carga temáticos, y microinteracciones moderadas.

Reglas: consistencia de spacing/border-radius, empty/error/success states explícitos, responsive sin overflow horizontal, contraste accesible.
